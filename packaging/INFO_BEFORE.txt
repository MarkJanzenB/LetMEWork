Welcome to Let Me Work (public beta)

Maintainer: Mark Janzen Bandola
Repo: https://github.com/MarkJanzenB/LetMEWork

Based on Kurt Chan's AI Job Hunt Agent (core scrape-and-score workflow).
This edition adds OpenCode, SQLite, onboarding, a local dashboard UI, and this installer.

This Setup puts Let Me Work on your PC. On the Select Additional Tasks page you can
opt in to install the OpenCode CLI if it is missing (recommended, checked by default).

After files are copied, Setup:
  1. Detects whether OpenCode is already installed
  2. If found — skips download
  3. If missing and you opted in — soft-installs from official sources (network):

  • Node.js LTS — via winget / Chocolatey / Scoop / nodejs.org MSI (if needed)
  • OpenCode — via npm (`npm install -g opencode-ai`) or Scoop / Chocolatey

It does NOT bundle a third-party opencode.exe inside this Setup.
Python libraries are already inside LetMeWork.exe.

What you still provide
  1. Firecrawl API key (required) — https://www.firecrawl.dev/app/api-keys
  2. Your resume (paste markdown or upload PDF)
  3. Optional: OpenRouter key — https://openrouter.ai/keys

After setup: complete onboarding (keys → resume → at least one job board).

What to expect (beta)
  • Useful local tool — not a cloud SaaS or auto-apply bot
  • AI match quality varies by model and resume
  • SmartScreen may warn (unsigned beta): More info → Run anyway
  • OpenCode install may need Retry or a new terminal for PATH

Privacy
  • API keys stay under your Windows AppData folder on THIS PC
  • Keys are never uploaded to the publisher and are not stored in the job database
  • Resume stays on this PC; AI providers receive extracted text when you run the agent
